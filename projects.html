Tools — shipped

On GitHub. Clone them, read the code, question the output.

ShippedPython · CLI

r3con — OSINT Recon Tool

Multi-phase recon pipeline: passive subdomain enumeration (crt.sh, HackerTarget, RapidDNS), HTTP probing, rule-based tech fingerprinting, DNS and WHOIS, banner grabbing, Shodan enrichment — then one structured report (JSON + TXT) with risk flags.

GitHub
ShippedPython · Scapy

NetWatch — Network IDS

Captures live traffic (or replays PCAPs), parses packets by protocol and runs a detection engine for five rule sets: SYN scans, port scans, ARP spoofing, DNS anomalies, and ICMP floods. Real-time alerts, plus a JSON + TXT session report on exit.

PythonScapyIDS
┌──(r3tro_n3o㉿kali)-[~] └─$ sudo python netwatch.py --live --iface eth0 # SYN · ARP spoof · ICMP · DNS · port scan # alerts: real time · JSON + TXT
GitHub
ShippedPython · AWS

CloudLens — Cloud Attack-Path Analyzer

Local-first attack-path analysis for an AWS environment: models identities, roles, resources and compute as a graph and finds the paths an attacker could actually chain from an identity to a sensitive resource. Runs on local JSON files — no cloud account, no spend.

PythonAWS IAMAttack graphs
┌──(r3tro_n3o㉿kali)-[~] └─$ python3 cloudlens/cli.py scan examples/bank-sim.json # identities → roles → resources # CRITICAL / HIGH / MEDIUM
