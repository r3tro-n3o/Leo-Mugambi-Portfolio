01 whoami

The story so far

Systems fail in interesting ways. This is how I got obsessed with finding out why — and what I'm building because of it.

"What happens if this is used in a way it was never meant to be?"

I'm Leo — some corners of the internet know me as r3tro_n3o. In 2023, scams and SIM-swap fraud were hitting people around me and nobody could explain how they worked. So I taught myself: Cybrary, OverTheWire, TryHackMe — then AfricaHackon's full curriculum and two ALX programs to fill the gaps.

Now I'm deep in CPTS prep, headed for cloud security, AWS-first. The long game is NOX — a company that makes cybercrime harder, not easier.

02 Capabilities

How I operate

Four lanes. Each card shows what I can do right now — no hidden sections.

01

Offensive Security

recon · web · network

Enumeration to exploitation: subdomains, open ports, fingerprinted services, web bugs (SQLi, XSS, IDOR, cmd injection), malware triage.

What I look for Forgotten dev subdomains · leaky headers · login forms with no rate limit · default creds
NmapMetasploitBurp SuiteShodanr3con
02

Defensive Security

hunting · DFIR · blue team

Follow the artifacts: event IDs, registry keys, prefetch. Rebuilding the attacker's timeline with Velociraptor hunts and detection rules.

What I look for Brute-force patterns · odd parent-child process chains · DNS tunneling · lateral movement
VelociraptorSysmonWiresharkCyberChef
03

Programming & Automation

python · bash · workflows

If I do it manually twice, I script it. Three tools shipped solve real problems I hit testing or hunting — and they're on GitHub.

Proof r3con (recon) · NetWatch (IDS) · CloudLens (AWS attack paths) — all shipped and public

Systems & Cloud

Find where trust is assumed but not enforced — over-permissive IAM, missing segmentation, unpatched services, default VPCs.
