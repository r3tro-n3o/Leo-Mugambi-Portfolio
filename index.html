r3con — OSINT Recon Tool

Multi-phase recon pipeline: passive subdomain enumeration, HTTP probing, rule-based tech fingerprinting, DNS and WHOIS, banner grabbing, Shodan enrichment — then one structured report (JSON + TXT) with risk flags.

ShippedPython · Scapy

NetWatch — Network IDS

Captures live traffic (or replays PCAPs), parses packets by protocol and runs a detection engine for five rule sets: SYN scans, port scans, ARP spoofing, DNS anomalies, and ICMP floods. Prints alerts in real time and writes a JSON + TXT report.

PythonScapyIDS
┌──(r3tro_n3o㉿kali)-[~] └─$ sudo python netwatch.py --live --iface eth0 # SYN · ARP spoof · ICMP · DNS · port scan # alerts: real time · JSON + TXT

ShippedPython · AWS

CloudLens — Cloud Attack-Path Analyzer

Local-first analyzer for an AWS environment: models identities, roles and resources as a graph and finds the paths an attacker could actually chain from an identity to a sensitive resource. Runs on local JSON files — no cloud spend.

PythonAWS IAMAttack graphs
